Week 7, Day 1 — student handout

Umesh Indrajith · In-memory students. No DB / JWT.

Outcomes

  • Structs + JSON tags (first_name style).
  • In-memory map[int]Student.
  • POST / GET / GET :id for students.
  • 400 on bad JSON; 404 when missing.

Model

type Student struct {
    ID        int    `json:"id"`
    FirstName string `json:"first_name"`
    LastName  string `json:"last_name"`
    Email     string `json:"email"`
    Phone     string `json:"phone"`
    Course    string `json:"course"`
}

Routes

POST /api/students
GET  /api/students
GET  /api/students/:id

Postman body

{
  "first_name": "Ada",
  "last_name": "Lovelace",
  "email": "ada@example.com",
  "phone": "0770000000",
  "course": "SE"
}

Status

CodeWhen
201Created
200List / get
400Bad JSON
404Unknown id

If it breaks

  • FirstName in JSON → add tags
  • always 400 → fix JSON / Content-Type
  • 404 on good id → Atoi the param
  • empty list → server restarted?

Homework
