Week 5, Day 1 — student handout

Umesh Indrajith · First SMS HTTP API. No DB / JWT today.

Outcomes

  • HTTP method, path, status, JSON body.
  • Tiny net/http server, then Gin.
  • GET /health and GET /api/hello on :8080.
  • Prove with curl and Postman.

Add Gin

cd backend
go get github.com/gin-gonic/gin
go mod tidy

Health (Gin)

r := gin.Default()
r.GET("/health", func(c *gin.Context) {
    c.JSON(http.StatusOK, gin.H{
        "status":  "ok",
        "message": "Backend is running",
    })
})
r.GET("/api/hello", func(c *gin.Context) {
    c.JSON(http.StatusOK, gin.H{"message": "hello from SMS"})
})
r.Run(":8080")

Prove it

go run ./cmd/server
curl -i http://localhost:8080/health
curl -s http://localhost:8080/api/hello

Status cheat sheet

CodeMeaning
200OK
400Bad request
404Not found
500Server error

If it breaks

  • refused → start the server
  • port in use → kill old process
  • gin missing → go get in backend/
  • Postman https → use http://
