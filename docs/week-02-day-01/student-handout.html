Bytes vs runes

len("café")                      // 5  (bytes)
utf8.RuneCountInString("café")   // 4  (letters / code points)
utf8.RuneCountInString("සිංහල")  // 5

len counts bytes (15 for සිංහල). A rune is one Unicode code point. සි is two runes: the letter plus the vowel sign. Do not index a string with s[0] and call it a letter.

Words to remember

TermMeaning today
Zero valueWhat you get if you do not assign: 0, "", false, nil
:=Declare and assign, inside a function only
ConversionYou write float64(n). The compiler will not guess
byte / runeuint8 / int32 (a Unicode code point)
go testRuns functions named Test… in *_test.go

If it breaks

  • := at top of file → use var
  • int + float64 → convert one side
  • prints 0xc000… → you forgot *
  • go test no module → go mod init
  • YYYY-MM-DD parse fails → layout is 2006-01-02
