Slices

s := make([]string, 0, 8)
s = append(s, "SE")          // always assign the result

a := []int{10, 20, 30, 40}
b := a[:2]
b = append(b, 99)            // may change a[2] — shared backing array

Slice header = pointer + length + capacity. Need independence? Copy into a new backing array.

Maps

count := make(map[string]int)
count["SE"]++
v, ok := count["SE"]         // comma-ok: missing vs present
if !ok { /* not found */ }
delete(count, "SE")

Writing to a nil map panics. Range order is randomised — do not assert print order in tests.

Words to remember

TermMeaning today
Backing arrayStorage underneath one or more slices
capHow far append can grow without reallocating
Comma-okv, ok := m[k] — was the key present?
Tagless switchswitch { case cond: }
_Blank identifier — intentionally unused

If it breaks

  • if score → need a bool comparison
  • append ignored → assign: s = append(s, x)
  • nil map write → make first
  • flaky map test → assert keys, not print order
  • go test no module → go mod init
