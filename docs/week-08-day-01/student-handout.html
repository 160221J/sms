Pointers, memory, repository layer

Move the student map out of handlers into StudentRepository. No Postgres. No JWT.

Outcomes

  • Use & and *; explain a nil pointer panic.
  • Know why handlers use pointer receivers.
  • Call a repository from handlers — HTTP does not own the map.

Shape

repo := repository.NewStudentRepository()
h := handlers.NewStudentHandler(repo)
r.POST("/api/students", h.Create)

Lab gate

  • Nil crash fixed
  • Repo owns map; handler has no map fields
  • Create + list + get still work; health green
